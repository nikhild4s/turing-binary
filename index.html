What is a Turing Machine?

A Turing Machine is a theoretical computer model with an infinite tape of cells, a read/write head, and a set of rules (transitions). It's the foundation of modern computation theory.

M = (Q, Σ, Γ, δ, q₀, Q_H) where δ is the transition function that decides what to do at every step.

How Increment Works

The machine scans right to find the LSB (rightmost bit), then moves left applying carry propagation: flip trailing 1s to 0, then flip the first 0 to 1 and halt.

Worst case: all-1s input (e.g. 1111→10000). The tape expands by one cell.

How Decrement Works

The machine scans right to the LSB, then moves left applying borrow propagation: flip trailing 0s to 1, then flip the first 1 to 0 and halt.

Decrement of zero is explicitly rejected — there is no smaller non-negative binary number.
